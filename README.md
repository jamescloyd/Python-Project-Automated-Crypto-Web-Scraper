# Python Project: A Simple Automated Crypto Web Scraper

In this web scraping project, I wrote a simple Python code to scrape the price of Bitcoin every minute from the Internet (Please find the link to the source below). It extracts the data, put it in a data frame, and export it to a csv file so that I can make use of the data very easily.

Source: https://coinmarketcap.com/currencies/bitcoin/
